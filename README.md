# LAN_Chat — 在线匿名聊天室

基于 Flask + SQLite 的局域网多房间匿名聊天系统（数据库课程设计）。

## 功能特性

- **双角色登录**：普通用户直接进入；管理员需密码（默认 `ADMIN`，可在管理页修改）
- **多房间**：每个房间独立数据库、独立上传目录、独立二维码
- **实时聊天**：SSE 推送消息 / 用户列表 / 房间事件
- **消息类型**：文本（敏感词过滤）、图片、文件（可设单文件限额）
- **用户管理**：禁言（倒计时）、踢出 + 黑名单、在线列表（含 IP）
- **消息管理**：撤回（时限内）、管理员强制删除、清空记录、房间级恢复出厂
- **数据查询**：统计视图（按用户/类型）、删除审计日志、按昵称搜消息/文件
- **收藏夹**：按用户收藏消息，支持图片/文件/文本分组展示
- **全局恢复出厂**：管理员页一键重置所有房间、数据、管理员密码

## 快速开始

```bash
pip install flask qrcode pillow
python app.py
```

启动后终端打印局域网访问地址（如 `http://192.168.x.x:5000/`），手机扫码或浏览器打开即可。

## 目录结构

```
LAN_Chat/
├── app.py                 # 主程序（路由 / 数据库 / 业务逻辑 / SSE）
├── lan_chat.db            # 主库：rooms 房间注册表 + config 配置
├── room_room_<id>.db      # 每房间独立库（profiles/messages/blacklist/...）
├── uploads_<room_id>/     # 每房间上传目录
├── static/qrcode/         # 房间二维码 + 入口二维码
└── templates/
    ├── login.html         # 登录入口页
    ├── rooms.html         # 管理员房间管理页
    ├── rooms_user.html    # 普通用户房间列表
    ├── index.html         # 聊天主页面（核心）
    └── admin.html         # 旧地址跳转兼容
```

## 权限说明

| 能力 | 普通用户 | 管理员 |
|------|---------|--------|
| 浏览开放房间 / 进入聊天 | ✓ | ✓ |
| 创建 / 删除 / 开关房间 | — | ✓（需 admin 会话） |
| 修改管理员密码 / 全局出厂 | — | ✓（需密码确认） |
| 房间内管理（禁言/踢出/设置） | — | ✓（`?admin=1` 进入） |

## 数据库设计要点

- 主库 `rooms` 为房间单一事实来源；房间配置热更新时同步写回
- 房间库各表以 `(room_id, ...)` 复合主键，兼容旧库自动迁移（补列回填）
- `message_audit` 由 DELETE 触发器自动记录，配合视图 `v_message_stats` / `v_message_type_stats` 做统计查询
- `config` 表存全局键值（`admin_password`）

## 默认账号

- 管理员密码：`ADMIN`（登录页选"管理员登录"输入）
- 普通用户：无需密码，输入昵称即可进入
